# Ecological companion article

This directory contains a hypothesis-driven ecological perspective based on the
certified descriptive findings of *Argentina Dengue Surveillance*.

It adds biological interpretation, explicit competing explanations, and
falsifiable predictions. It does not perform new epidemiological analysis,
calculate indicators, fit models, or modify the certified project artifacts.

## Contents

- `dengue_population_ecology_perspective.qmd`: standalone Quarto manuscript.
- `references.bib`: verified bibliography used by the manuscript.
- `literature_evidence_matrix.md`: claim-level evidence and limitation audit.

The manuscript reuses three certified figures from `../figures/` unchanged and
adds one inline conceptual Mermaid diagram. Render from the project root with:

```bash
quarto render articles/dengue_population_ecology_perspective.qmd
```

The rendered manuscript is not yet published publicly.
