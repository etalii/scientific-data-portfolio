# Deferred DataSpec framework feedback

These observations come from the dengue retrospective pilot. They are evidence
for comparison after the climate portability pilot, not authorization to change
common schemas, validation, lifecycle rules or skills now.

## Generalizable observations

- Review findings should identify the exact claim/objective, revision and review
  dimension. The first five historical findings repeated a generic message.
- Literal label equality and semantic equivalence need distinguishable policies.
  Existing equivalent caption/alt wording was not a literal implementation of
  the reconstructed visual strings.
- Human review packets benefit from grouped decisions with individually recorded
  dispositions. Three decisions covered nine requirements without losing detail.
- Reproducibility scope needs to distinguish calculations, selected presentation,
  complete report rendering, source acquisition and environment portability.
- Accepted-with-edit and partial dispositions must survive revision history;
  a passing final review must not erase the original requirement for revision.
- Historical snapshots need explicit configuration replay. Changes to the current
  config correctly stale historical file references; old hashes must not be
  rewritten to make history appear current.

## Dengue-specific observations

- The 24 jurisdictions include CABA; the complete set should not be labeled
  "24 Argentine provinces" in the accepted presentation.
- Four highlighted jurisdictions are selected contrasts, not the four largest
  rank movements. Ordinal distance is not effect size or temporal change.
- Preserve unknown geography, population vintage/reference date, incomplete
  residence semantics, and the distinction between geographic assignment and
  surveillance completeness.
- The accepted scope is calendar-year 2024 and the contemporary denominator.
  Seasonal interpretation, alternative-denominator stability and whole-report
  accessibility certification remain outside this pilot.

No common component was changed to resolve these project-specific findings.
